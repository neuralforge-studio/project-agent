# BOARD-014: Board TUI를 여는 시간이 v0.5.0에서 v0.4.0의 2~2.5배로 측정됐습니다(16×16, n=2)

- Opened: 2026-11-11
- Scope: project-agent
- Severity: S2
- Related: PERF-001, BOARD-012, BOARD-013, PERF-003, PERF-004

## Symptom
PERF-001 측정 결과 D(16×16, v0.4.0 대 v0.5.0)에서 Board TUI가 ready를 표시하기까지의 시간이 늘었습니다. popup은 1.78초에서 3.54초로, sidebar는 3.42초에서 8.61초로 늘었습니다. 반복이 2회라 구간과 판정은 없습니다. 같은 run에서 다른 연산은 대부분 개선이었습니다. 사용자가 Board를 열 때마다 겪는 시간입니다.

## Evidence
- PERF-001 Result "측정 결과 D"의 `board_popup_ready`·`board_sidebar_ready` 행입니다(n=2/2, host load 9~40, CPU 열 없음).
- v0.4.0과 v0.5.0 사이에서 Board 경로에 닿는 변경은 다음과 같습니다.
  - BOARD-012(`tmux_control._snapshot`, sync·toggle)
  - PERF-002·PERF-003(진입점 `-S`, 번들. TUI 명령은 site를 처리하는 일반 경로)
  - SESSION-011·SESSION-012(agent_session)
- 그 뒤 main에는 PERF-004(`agent_session/__init__.py`가 package를 처음 import할 때 번들 reader를 설치)와 BOARD-013(TUI 다시 그리기·목록 재사용)이 들어왔습니다.
- 늘어난 것이 실제인지, 무엇 때문인지는 아직 모릅니다.

## Contract
- Board를 여는 시간은 v0.4.0보다 나빠지지 않습니다.
- 표시 내용은 바꾸지 않습니다.

## Disposition

- 2026-11-11 Leader: open -> todo. 측정 근거 있는 회귀 후보
