# project-agent

This repository is the independent development home for Project Team,
Project Item, Project Board, and Agent Session. The components currently run
from `agent.desk`; their source and installation have not yet been migrated.

The project uses its own CR and decision items under `agent/`. Migration work
will define one source for each component and a separate installation path.
SSH worker seats are described by a host and remote directory; the existing
MacBook seat is one SSH seat configuration.
